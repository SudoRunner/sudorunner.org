# Research & Labs

This section is for hands-on cybersecurity research, lab work, technical notes, and practical security experiments.

The goal is to document how I investigate security concepts, build lab environments, test workflows, analyze findings, and translate technical lessons into clear operational takeaways.

## Featured Lab Collection

### [IST 451 Security Labs Collection](/research-labs/ist-451-security-labs-collection/)

A redacted academic lab collection covering service identification, Apache hardening, OpenVAS vulnerability scanning, SQL injection concepts, malware investigation, OT/ICS disruption, Snort IDS configuration, iptables firewalling, wireless security, and controlled CTF practice.

## Focus Areas

### Vulnerability Management Labs

Hands-on notes related to vulnerability intake, triage, prioritization, ownership, remediation tracking, exception handling, validation, and closure.

### Security Operations Workflows

Research and notes on how security teams move from detection or finding to action, including escalation paths, documentation, and operational decision-making.

### ServiceNow SecOps Practice

Lab-based exploration of ServiceNow SecOps concepts, especially Vulnerability Response, vulnerable items, assignment groups, remediation tasks, and workflow design.

### Technical Notes

Shorter writeups on cybersecurity concepts, tools, frameworks, and lessons learned while studying or building.
