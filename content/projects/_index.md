## Redaction Standard

Before publishing any project, I review it for:

* Client names or identifying information
* Student names or group member names
* Screenshots containing personal data
* Internal system names
* Full source code or full solution files
* Credentials, tokens, or API keys
* Sensitive infrastructure details
* Anything that could violate academic, employer, or client confidentiality

The goal is to demonstrate skill without exposing information that should remain private.
