# Projects

This section contains selected cybersecurity, ServiceNow, academic, and technical projects that demonstrate practical security knowledge, structured problem solving, and hands-on experience.

Projects are presented in a **redacted case-study format**. The goal is to show technical depth and decision-making without exposing private data, client information, full solutions, or sensitive implementation details.

## Project Format

Each project may include:

* Problem statement
* Environment and tools used
* My role and responsibilities
* What I built, analyzed, or documented
* Redacted screenshots, diagrams, or artifacts
* Lessons learned
* What I would improve with more time

## Redaction Standard

Before publishing any project, I review it for:

* Client names or identifying information
* Student names or group member names
* Screenshots containing personal data
* Internal system names
* Full source code or full solution files
* Credentials, tokens, or API keys
* Sensitive infrastructure details
* Anything that could violate academic, employer, or client confidentiality

The goal is to demonstrate skill without exposing information that should remain private.
