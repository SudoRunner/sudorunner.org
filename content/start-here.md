# 60-Second Portfolio Review

I help organizations **organize, track, and fix cybersecurity weaknesses** before they turn into bigger risks.

In practice, that means I help cybersecurity teams turn technical findings into clear ownership, assigned work, remediation tracking, validation, reporting, and closure.

<div class="sr-callout">

<strong>In simple terms:</strong> I help connect cybersecurity work with real execution so teams know what needs to be fixed, who owns it, what the status is, and when the risk has been addressed.

</div>

My main technical focus is **ServiceNow Security Operations**, especially **Vulnerability Response**.

<strong>Primary focus:</strong> ServiceNow Security Operations and Vulnerability Response, supported by cybersecurity delivery, security operations, and OT/ICS-aware workflow thinking.
